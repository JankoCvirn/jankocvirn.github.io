About me

For more than 11 years I've been building Android apps in Kotlin and Java, from small consumer apps to large multi-module codebases for phones, Android TV and Android Automotive. These days I work Compose-first, with Coroutines and Flow, MVI/MVVM and Clean Architecture.

I work collaboratively and iteratively: short feedback loops, clear communication and code your team can maintain after I'm gone. I'm equally comfortable owning a feature end to end on my own.

I use AI tooling such as Claude Code in my daily workflow for refactoring, code review and test generation, so clients get well-tested work delivered faster.
